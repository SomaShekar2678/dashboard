# Atmos — Home Control Dashboard

A standalone smart-home dashboard prototype built from scratch with React, TypeScript, and Vite.

## Features
- Responsive dark dashboard layout
- Overview with room cards, environment metrics, energy chart, and recent activity
- Interactive device toggles
- Scene activation controls
- Music player interface with local demo state

## Run locally
Requires Node.js 20+.

```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

This is a frontend-only prototype. All device, sensor, scene, and music data is illustrative local state; it does not control physical devices or connect to a backend.
